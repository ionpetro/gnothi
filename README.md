# Gnothi

*Γνῶθι σαυτόν. Γνῶθι το 20.*

**Open source** under the [MIT license](LICENSE). Free, and it will always be free. No account, no ads. The only thing we do is measure how it's used with [PostHog](https://posthog.com) (anonymous; session recordings hide anything typed) so we can make it better. Corrections to the Greek are very welcome: open an issue or a pull request.

**English in brief.** Gnothi is a playful, Duolingo-style web app that teaches Ancient Greek to a Greek Γ΄ Λυκείου student sitting the Panhellenic exams (Αρχαία Ελληνικά, Ομάδα Προσανατολισμού Ανθρωπιστικών Σπουδών, Monday 31 May 2027). It is the sibling of [Carpe](https://github.com/ionpetro/carpe) (Latin) and [Skepsis](https://github.com/ionpetro/skepsis) and keeps their tricks: guess-first openers, build-from-tiles, match pairs, yes/no sorting, spaced review, streaks with freezes and no hearts, badges, a speed round, a mascot with moods, exam-style prompts phrased exactly as the committee phrases them. The UI and every explanation are in modern Greek with the terminology Greek schools use; the Ancient Greek is polytonic as the school books print it and follows Οικονόμου's grammar and Μουμτζάκης's syntax. Plain JavaScript, no framework, one HTML file. Run `npm test && npm run build`, then serve `app/vercel/`. The rest of this file is in Greek, for the people who will use and extend it.

## Τι είναι

Μια εφαρμογή για το κινητό και τον υπολογιστή που κάνει τα Αρχαία Ελληνικά των Πανελλαδικών παιχνίδι: τέσσερα λεπτά τη φορά, με τις εκφωνήσεις ακριβώς όπως τις βάζει η επιτροπή («τον ίδιο τύπο στον άλλο αριθμό», «να χαρακτηρίσετε πλήρως συντακτικά», «να τον μετατρέψετε στο προσδοκώμενο», «σε ποια λέξη αναφέρεται η αντωνυμία»). Μασκότ η **Γλαύκη**, μια μικρή κουκουβάγια της Αθηνάς. Οι πόντοι είναι **οβολοί** (6 οβολοί = 1 δραχμή), οι άδειες του σερί **ἐκεχειρίαι**, ο γρήγορος γύρος είναι το **Στάδιο**, ο δρόμος των μονάδων η **Ιερά Οδός**, οι τίτλοι από την αθηναϊκή ζωή (Παῖς, Ἔφηβος, Πολίτης, Βουλευτής, Γραμματεύς, Ῥήτωρ, Στρατηγός, Ὀλυμπιονίκης, Ἀκαδημαϊκός, Μάντις, Φιλόσοφος, Γνῶθι το 20).

Τι περιέχει (14 μονάδες στην Ιερά Οδό· σχεδιασμός στο `research/CURRICULUM.md`):

| Θέμα εξέτασης | Μονάδες | Τι εξασκείς |
|---|---|---|
| Α1 Κατανόηση (10) | u2, u5, u8, u11 | Σωστό/Λάθος με τεκμηρίωση, «σε ποια λέξη αναφέρεται η αντωνυμία», τα 19 κείμενα αναφοράς στο επίπεδο της λέξης |
| Β1 Ερμηνευτική (10) | u2, u5, u8, u11 | Η αλυσίδα της απάντησης: θέση → παράθεμα → ερμηνεία → σύνδεση → συμπέρασμα· εκφραστικά μέσα |
| Β2 Παράλληλο κείμενο (10) | u2, u5, u8, u11 | Ομοιότητα, διαφορά ή δεν προκύπτει, πάντα με παράθεμα και από τα δύο κείμενα |
| Β3 Ετυμολογία (10) | u1 (+ κείμενα) | Οικογένειες ριζών και μεταπτωτικά θέματα (ἔδει~ένδεια, εἴληφε~λήμμα), βρες-στο-κείμενο, συμπλήρωσε, αντιστοίχιση 5+2, η άλλη σημασία |
| Β4 Εισαγωγή (10) | u13 | Σωστό/Λάθος και α/β/γ από τις Εισαγωγές (Σωκράτης, Πλάτων, Αριστοτέλης), με την «παγίδα» δίπλα στο σωστό |
| Γ1 Μετάφραση (20) | u7, u14 | Οι ~600 λέξεις του αδιδάκτου, μόρια, ὡς/ἄν/ὥστε· προτάσεις αττικής πεζογραφίας με πλακίδια |
| Γ2 Κατανόηση (10) | u14 | Τα σημεία που περιμένει η επιτροπή, ως λίστα ελέγχου |
| Γ3 Γραμματική (10) | u3, u4, u6, u9 | Γ΄ κλίση, παραθετικά, αντωνυμίες, αρχικοί χρόνοι, αύξηση, εγκλίσεις, προστακτική, ευκτική, απαρέμφατα, μετοχές, -μι |
| Γ4 Συντακτικό (10) | u10, u12 | «ΛΕΞΗ: είδος στο «ΚΥΡΙΑ ΛΕΞΗ»», δευτερεύουσες σε έξι βήματα, υποθετικοί λόγοι, πλάγιος λόγος, ανάλυση μετοχής |

Πώς παίζεται:

- **Μάθημα** («μέρος»): ξεκινά με «Μάντεψε πρώτα» χωρίς βαθμό, μετά κάθε κάρτα διδάσκεται σε μια ανάσα και ρωτιέται αμέσως, μετά οι δύσκολες ερωτήσεις (τύπος με πλακίδια ή γραφή σε πολυτονικό, αρχικοί χρόνοι σε έξι θέσεις, αντιστοίχιση, ταξινόμηση, εφάρμοσε-τον-κανόνα σε άγνωστο τύπο), και στο τέλος ξαναέρχονται όσα έχασες. Λέξεις που έμαθες σε προηγούμενη μονάδα δεν ξαναδιδάσκονται· ρωτιούνται.
- **Επανάληψη**: κουτιά Leitner (1, 3, 7, 14, 30, 60 μέρες). Από τον Μάιο καμία επανάληψη δεν πέφτει μετά τις 24 Μαΐου.
- **Θέμα της ημέρας**: Δευτέρα Γ3, Τρίτη Γ4, Τετάρτη Α1+Β3, Πέμπτη Γ1+Γ2, Παρασκευή Β4, Σάββατο Β1+Β2, Κυριακή μικτό, με τις πραγματικές μονάδες. Ίδιο όλη μέρα.
- **Διαγώνισμα**: και τα 9 Θέματα σε μικρογραφία, 100 μονάδες, με ανάλυση ανά Θέμα και το ≈ /20 στο τέλος.
- **Στάδιο**: 20 δευτερόλεπτα, τρεις επιλογές, ένα λάθος και ο αγώνας τελειώνει.
- **Λέξεις**: 25 κάρτες σε 2 λεπτά, κατευθυνόμενες από το «στο σχολείο είμαστε στην ενότητα …» του Φακέλου.
- **Τετράδιο λαθών**: ό,τι έχασες δύο φορές, με τα χειρότερα πρώτα.
- **Σερί**: τα Σαββατοκύριακα δεν το σπάνε, μία ἐκεχειρία την εβδομάδα και μία κάθε 7 μέρες σερί (έως 2). Χωρίς καρδιές, χωρίς τιμωρίες. Η αρχική οθόνη λέει ειλικρινά ότι οι μισοί υποψήφιοι γράφουν κάτω από 10: το 10 είναι η πρώτη νίκη.

Η ημερομηνία εξέτασης (Δευτέρα 31 Μαΐου 2027, 08:30) προέρχεται από αναδημοσιεύσεις του προγράμματος του υπουργείου και αλλάζει από τις ρυθμίσεις· επιβεβαίωσέ την τον Μάρτιο.

## Πώς τρέχει

```
npm test          # validator + έλεγχοι engine (node:test) σε κάθε μονάδα
npm run validate  # αναφορά του validator για όλες τις μονάδες (0 errors απαιτούνται)
npm run build     # app/dist/index.html (ένα αρχείο) + app/vercel/ (site: app, /lexiko, /about, sitemap, manifest)
npm run build:example   # με τη μονάδα-παράδειγμα, για να δεις τη διεπαφή πριν γραφτούν οι μονάδες
```

Τοπικά: `npm run build && python3 -m http.server 8765 --directory app/vercel` και άνοιξε `http://127.0.0.1:8765/`. Deploy: `npm run build && cd app/vercel && vercel deploy --prod` (με `POSTHOG_KEY` στο `app/.env`, που δεν μπαίνει στο git, φορτώνεται το PostHog με `app = gnothi`· χωρίς αυτό, κανένα analytics). Η πρόοδος μένει στη συσκευή (`localStorage`, κλειδί `gnothi:v1`).

Χρειάζεται μόνο Node (χωρίς εξαρτήσεις). Οι γραμματοσειρές (Nunito για τη διεπαφή, Noto Serif και GFS Didot για το πολυτονικό) φορτώνουν από το Google Fonts και έχουν fallback.

## Πώς είναι οργανωμένο το περιεχόμενο

```
app/
  src/units/u1.js … u14.js   μία μονάδα ανά αρχείο, απλά αντικείμενα JS (σχήμα: app/CONTENT_SCHEMA.md)
  src/units/u0_example.js    το παράδειγμα με όλα τα είδη καρτών (δεν μπαίνει στο build)
  src/engine.js              καθαρή λογική: ημερομηνίες, σερί, κουτιά, πολυτονικός έλεγχος, κατασκευή ερωτήσεων, Θέμα ημέρας, διαγώνισμα, Στάδιο, τίτλοι
  src/app.js                 η διεπαφή στα ελληνικά (Γλαύκη, Ιερά Οδός, Λεξικό, Εγώ, οι renderers κάθε είδους ερώτησης)
  src/style.css, shell.html  αθηναϊκή παλέτα, dark mode, πρώτα για κινητό
  tools/validate.js          ο validator του περιεχομένου
  test/                      content.test.js (κάθε μονάδα περνά τον validator, κάθε ερώτηση παίζεται) και engine.test.js
  build.mjs, site.mjs        build ενός αρχείου και το site για το Vercel
research/                    η έρευνα πίσω από το περιεχόμενο (CURRICULUM.md, syllabus.md, pastpapers.md, texts, vocab, morphology, syntax, interpretation, traps)
```

Τα 14 είδη καρτών: `word` (λέξη με αρχικούς χρόνους ή γενική, γένος, κλίση, ετυμολογία, παγίδα), `sentence` (πρόταση κειμένου αναφοράς ή αδιδάκτου με πλακίδια μετάφρασης, συντακτικές σημειώσεις, «βρες», αναφορά αντωνυμίας, Σ/Λ, εκφραστικά μέσα), `form` (τύπος Γ3 με κελί, αποδεκτές γραφές, `strict` όταν μετρά ο τόνος, πλακίδια, κανόνα), `rule` (κανόνας με 1-5 ερωτήσεις ελέγχου), `role` (Γ4α «είναι … στο …» με την κύρια λέξη), `clause` (δευτερεύουσα σε έξι κουτιά: είδος, εισαγωγή, άρνηση, λειτουργία, εξάρτηση, εκφορά), `transform` (Γ4β μετατροπή με πλακίδια), `fact` (Β4 με την «παγίδα» δίπλα), `hook` (Β3 ετυμολογία: ρίζα, μεταπτωτικό θέμα, μακρινός συγγενής), `sense` (η ίδια λέξη με άλλη σημασία), `claim` (Β1 αλυσίδα απάντησης), `parallel` (Β2 ομοιότητα/διαφορά/δεν προκύπτει), `unseen` (αδίδακτο με σημεία Γ2), `trap` (παγίδα: λάθος → σωστό).

Κάθε κάρτα δηλώνει `status` (`book` ελέγχθηκε στα σχολικά βιβλία, `exam` από πραγματικό θέμα ή κλειδί, `general` καθιερωμένα Αρχαία εκτός σχολικών βιβλίων, `unsure` «προς έλεγχο» από φιλόλογο), `src` (πού ελέγχθηκε) και, για τα κείμενα, `unit_ref` (τον κωδικό του Φακέλου). Οι εμφανίσεις σε θέματα (`exam: [2026]`) προέρχονται μόνο από θέματα που διαβάστηκαν (`research/pastpapers.md`). Δεν υπάρχουν εφευρεμένα ποσοστά.

Κανόνες γραφής: τα Αρχαία πολυτονικά, όπως τα τυπώνει ο Φάκελος και η Γραμματική Οικονόμου· ο έλεγχος αγνοεί τόνους, πνεύματα, υπογεγραμμένη, κεφαλαία και στίξη, όχι όμως γράμματα· στους τύπους `strict` μετρά και ο τόνος (μισός βαθμός για λάθος μόνο στον τόνο). Ο validator απορρίπτει μονοτονικό κείμενο σε αρχαιοελληνικά πεδία, ελέγχει ότι κάθε μετάφραση και μετατροπή χτίζεται από τα πλακίδιά της, ότι οι λάθος επιλογές δεν συμπίπτουν με τη σωστή, ότι οι αντωνυμίες και οι λέξεις του «βρες» υπάρχουν στο κείμενο.

Για να προσθέσεις περιεχόμενο: αντέγραψε το σχήμα από το `u0_example.js`, γράψε στο αντίστοιχο `uN.js`, τρέξε `npm test`.

## Πηγές

Όλα στο `research/` (η έρευνα έγινε 2026-11-02· τα αρχεία λένε τι διαβάστηκε ολόκληρο και τι όχι): `syllabus.md` (εξεταστέα ύλη 2027, μορφή και ημερομηνία εξέτασης), `pastpapers.md` (θέματα 2021-2026 και παλαιότερα), `texts.md` + `texts.jsonl` (τα 19 κείμενα αναφοράς), `vocab.md` + `vocab.jsonl` (το λεξιλόγιο του αδιδάκτου με συχνότητες), `morphology.md`, `syntax.md`, `interpretation.md` + `cognates.jsonl`, `traps.md`, `CURRICULUM.md`. Τα σχολικά βιβλία σε κείμενο (`source-data/`), τα ακατέργαστα θέματα (`pastpapers-raw/`) και τα επίσημα έγγραφα (`official-*.txt`) μένουν εκτός git: πνευματικά δικαιώματα ΙΤΥΕ «Διόφαντος». Γι' αυτό και η εφαρμογή διδάσκει τα αρχαία κείμενα (κοινό κτήμα) με δικές της μεταφράσεις και σχόλια.
